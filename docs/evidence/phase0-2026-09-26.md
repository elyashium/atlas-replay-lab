## Replay, gate, and report

- Baseline causal hash matched, but all four screenshot checkpoints diverged
  beyond replay tolerance. The first-frame comparison in the full run was
  9.699% differing pixels / 0.9775 perceptual score; product detail was 41.911%
  / 0.9976. Replay reported `reproduced=false`.
- Adaptive causal hash matched, but all four screenshots also diverged; its
  first-frame comparison was 100% differing pixels / 0.7585 perceptual score.
- `artifacts/gate/report.json` returned HOLD: the no-WebGL profile failed the
  blank-first-frame invariant and score floor, and adaptive replay did not
  reproduce. Budget breaches were warnings, not blockers.
- `artifacts/report.html` was generated and includes matrix, both replay
  results, gate, judge, and engine comparison. The report page itself was not
  visually inspected at desktop/mobile sizes in this run. Matrix screenshots
  and the no-WebGL first-frame image were inspected during debugging.
