## What was exercised

The new `matrix --target` path ran the checked-in controlled staging scene. The scene is a local Atlas fixture, not an unaffiliated team's app. A controlled regression removed the visible start button's handler; the selector journey then timed out waiting for `[data-atlas-session-ready]` on every critical profile. ## Controlled regression

With the start handler removed and contract build id set to `fixture-broken-v1`:

```powershell
node bin/atlas.js matrix --target examples/target-contract.json --retry 0 --out artifacts/phase1-failure
node bin/atlas.js gate --matrix artifacts/phase1-failure/report.json --out artifacts/phase1-failure/gate
```

The matrix recorded a failed step on all three profiles: `waitForVisible timed out for selector [data-atlas-session-ready]`. Matrix exit was 0 because it captured all profiles; gate exit was 1 and target verdict was HOLD. The run took 36.18 s. A high Atlas score did not override the failed declared journey.

## Limits and next validation

- The controlled page is a WebGL API/fallback smoke fixture, not a representative 3D/WebAR experience or a third-party customer app.
- Target authorization is a local operator attestation. The contract checks top-level navigation origins only; subresource egress is not isolated or allowlisted. Do not expose this CLI as a public arbitrary-URL service.
- There is no organization auth, secret store, queue, hosted artifact store, object-level authorization, enforced retention, audit log, or server-side SSRF protection. Credentials are read from `ATLAS_*` environment variables and never written to reports.
- Screenshot redaction uses selectors and CSS blur. It is not a guarantee that all sensitive content is removed.
- `target.buildId` and `ATLAS_BUILD_ID`/`GITHUB_SHA` are recorded for manual attribution. Automatic cross-report diffing and captured customer-input replay are not implemented.
- No outside studio URL was supplied, so no unaffiliated staging experience was tested. Phase 1's real-customer acceptance remains unverified until a studio provides an authorized staging URL, target contract selectors and any out-of-band test credentials.
- There is no separate lint, typecheck or build script in this repository. `npm test`, `doctor`, the browser target matrix, release gate and HTML report were run; no package install or dependency was added.
